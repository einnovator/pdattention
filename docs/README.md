# Progressive Retrieval Attention Paper Program

This repository is organized as a multi-paper research program around Progressive Retrieval Attention (PRA).

## Papers

- `docs/papers/paper0_position/` — Vision and position paper.
- `docs/papers/paper1_standalone_pra/` — Standalone PyTorch PRA architecture and experiments.
- `docs/papers/paper2_hf_integration/` — Hugging Face integration with pretrained models.
- `docs/papers/paper3_runtime_vllm/` — KV-cache and vLLM/runtime integration.
- `docs/papers/paper4_scaling_theory/` — Scaling, theory, and comparative analysis.

## Shared material

- `docs/shared/references.bib`
- `docs/shared/macros.tex`
- `docs/shared/figures/`

Each paper has its own `AGENTS.md` for Codex and a starter LaTeX manuscript.
