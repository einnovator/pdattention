# AGENTS-Paper0-Position

## Mission
Transform the Position Paper from a proposal of a new attention mechanism into a manifesto for a new memory architecture for foundation models.

## Core goals
- Reframe PRA as a demand-driven context architecture, not merely retrieval.
- Position PRA as a unification of long-context transformers, RAG, RETRO, agentic systems, Toolformer, MCP and IDE assistants.
- Strengthen the thesis that references become first-class computational objects.
- Add a full "Virtual Memory for Transformers" section comparing CPU virtual memory (paging, address spaces, caches, lazy loading) with transformer memory hierarchies.
- Expand discussion of URI identity, provenance, freshness, permissions, hierarchy and cache lifetime.
- Add a section relating PRA to embodied cognition and referential memory in humans.
- Add a section on future foundation-model memory stacks (weights, working memory, episodic memory, semantic memory, tools, world models).
- Expand enterprise applications: software engineering, data analytics, BI, SQL, GitHub, Confluence, Jira, Snowflake, scientific literature, legal and medical assistants.
- Add publication-quality figures:
  - Evolution of context architectures
  - Context graph
  - Recursive anchor expansion
  - Virtual-memory analogy
  - PRA lifecycle
  - Relation to RAG and agents
- Strengthen the conclusion into a long-term research vision.
- Ensure every claim is carefully scoped and falsifiable.
