# Paper 6: PRA-vLLM

This directory contains the Paper 6 manuscript. Structured measurements live
under `docs/papers/shared/results/paper6_vllm/`; shared registry rows and plots
are generated by `experiments/engine_serving/summarize.py`.

The current evidence is deliberately bounded. It validates vLLM-Metal serving,
Automatic Prefix Caching coexistence, selected-text recovery, and the SDK's
logical-block lifecycle. It does not claim engine-native PRA K/V execution.

Rebuild the generated artifacts and paper from the repository root:

```bash
python -m experiments.engine_serving.summarize
cd docs/papers/paper6_vllm
latexmk -pdf -interaction=nonstopmode -halt-on-error paper.tex
```
