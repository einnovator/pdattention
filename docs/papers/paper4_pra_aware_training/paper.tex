\begin{abstract}
Progressive Retrieval Attention (PRA) can route to external references and
materialize their layer-native key/value (K/V) state, yet a transformer trained
only with ordinary self-attention need not know how to use that state. We isolate
this consumer-learning problem in a controlled associative-chain model. Reference
identities are fixed by an oracle, reference K/V remains inside the autograd graph,
and memory joins local K/V under the model's ordinary attention softmax. Starting
from one matched LocalSA checkpoint per seed, we compare Frozen PRA, three LoRA
scopes, full-weight continued training, and PRA-native training from scratch. Each
regime is evaluated with no memory, matched distractors, exact evidence, and the
whole parent. Across \PaperFourSeedCount{} paired seeds, the best change in the
correct-memory margin effect over Frozen is \PaperFourBestMarginEffect{} for
\PaperFourBestMarginRegime{}. Evidence-only accuracy rises from
\PaperFourFrozenEvidenceAccuracy{} Frozen to \PaperFourConsumerEvidenceAccuracy{}
with Consumer LoRA and \PaperFourNativeEvidenceAccuracy{} from scratch, while
whole-parent accuracy plateaus near one half. The controlled gate passes
\PaperFourCriteriaPassed{} preregistered criteria and yields the decision
\texttt{\PaperFourGateDecision}. These results concern oracle-selected memory
consumption in a sub-million-parameter diagnostic model. They do not establish
learned routing, language-model scaling, or deployment efficiency.
\end{abstract}

\section{Introduction}

Retrieval-augmented systems are often evaluated as if selecting the right text
were sufficient. Selection is only one boundary. The downstream transformer must
also turn retrieved state into a useful residual update without being distracted
by irrelevant state. Architectures trained with retrieval in the loop, including
REALM, RAG, and RETRO, make this interface part of learning
\cite{guu2020realm,lewis2020rag,borgeaud2022retro}. A frozen transformer retrofitted
with a new memory path has no such guarantee.

PRA makes this distinction unusually visible. It stores historical token K/V in
the same representation used by a transformer's attention layers, while compact
gists are only an address index. Once a reference is selected, full token K/V is
placed before local K/V under a joint softmax. This avoids a separate
cross-attention value space, but native format does not imply native use. Queries,
memory keys, values, output projections, and downstream feed-forward layers were
all optimized for a different context topology.

This paper asks a deliberately narrower question before spending compute on a
larger language model:

\begin{quote}
When memory identity and physical K/V are correct, how much transformer
plasticity is needed before sparse memory improves the answer?
\end{quote}

The experiment is a causal gate, not a benchmark race. We reuse randomized
associative chains, hold the PRA topology fixed, and change only adaptation
capacity. The design follows a strict ladder from no trainable parameters through
targeted low-rank updates \cite{hu2022lora} to full and from-scratch training.
Four memory interventions separate useful state from the generic effect of adding
tokens. Layerwise attention and representation-portability measurements then show
where any output change enters the network.

\paragraph{Contributions.}
We provide (i) a differentiable native-KV training path that preserves the same
joint attention operation used at inference; (ii) a matched six-rung PRA
adaptation ladder plus GlobalSA and LocalSA controls; (iii) causal metrics linking
memory identity to attention, residual state, answer margin, and prediction; and
(iv) a stage-gated result that explicitly decides whether larger-model work is
warranted.

\section{Why a Native Interface May Still Be Foreign}

Consider a decoder layer $\ell$ with local hidden state $H_L^{(\ell)}$ and a
separately encoded memory sequence $H_M^{(\ell)}$. PRA reuses the layer's ordinary
projections:
\begin{align}
Q_L^{(\ell)} &= W_Q^{(\ell)}\operatorname{LN}(H_L^{(\ell)}),\\
K_M^{(\ell)},V_M^{(\ell)}
 &= W_{K,V}^{(\ell)}\operatorname{LN}(H_M^{(\ell)}),\\
K_L^{(\ell)},V_L^{(\ell)}
 &= W_{K,V}^{(\ell)}\operatorname{LN}(H_L^{(\ell)}).
\end{align}
After the configured positional transform, memory and local keys share one
normalizer:
\begin{equation}
A^{(\ell)} = \operatorname{softmax}\!\left(
\frac{Q_L^{(\ell)}[K_M^{(\ell)};K_L^{(\ell)}]^\top}{\sqrt{d_h}}
+ \mathcal{M}_{\mathrm{causal}}
\right),
\quad
U^{(\ell)} = W_O^{(\ell)}A^{(\ell)}[V_M^{(\ell)};V_L^{(\ell)}].
\end{equation}
Memory positions are visible to every local query; the local block remains causal.

This operation introduces no cross-attention projection. Nevertheless, four
mismatches can remain. A query may not score remote keys correctly. Memory keys
may depend too strongly on the context in which they were encoded. Memory values
may point in directions the downstream residual stream does not interpret. Later
layers may erase a useful update. Frozen evaluation conflates all four. The
adaptation ladder opens them in a controlled order.

\section{Differentiable Oracle-Memory Training}

Offline PRA caches detach reference state so one encoding can serve many queries.
That is the correct inference boundary but the wrong training boundary. During
Gate 0, the selected reference tokens are encoded in the same forward graph as the
query. Immediately before each PRA consumer layer, the model captures
$K_M^{(\ell)},V_M^{(\ell)}$ with detachment disabled. The query then consumes those
tensors through the native joint softmax above. Gradients can reach Q/K/V/O,
reference production, and subsequent consumers according to the selected regime.

\begin{verbatim}
memory_h = embed(reference_tokens)
for layer in decoder:
    if layer is PRA:
        memory_kv[layer] = project_kv(LN(memory_h), detach=False)
    memory_h = layer.local_forward(memory_h)

query_h = embed(query_tokens)
for layer in decoder:
    if layer is PRA:
        update = native_joint_attention(LN(query_h), memory_kv[layer])
        query_h = query_h + update
        query_h = query_h + FFN(LN(query_h))
    else:
        query_h = layer.local_forward(query_h)
\end{verbatim}

Oracle selection is intentional. Training a router, materializer, and consumer at
once would make a negative output result uninterpretable. Evidence masks are used
only after the forward pass to divide final-token attention into evidence and
distractor mass. They never enter model input or loss.

\section{Controlled Experiment}

\subsection{Task and matched architectures}

Each example draws fresh entity and relation symbols, builds a path of one to four
facts, adds relation-sharing and label-relation distractors, and asks for the final
entity. Stable entity-to-answer memorization is therefore unavailable. Facts are
independently addressable references. The complete parent trains matched GlobalSA
and LocalSA models; PRA receives a short query as direct context and selected facts
as external K/V.

All models have 64 hidden dimensions, eight decoder layers, four heads, RoPE, and
a 256-token operation limit. LocalSA uses a 16-token window. PRA replaces attention
at zero-indexed layers 3 and 7, leaving LocalSA/FFN assimilation between memory
interventions. This model is far below the nominal $<100$M Tier-0 ceiling: the goal
is mechanistic discrimination at low cost.

\subsection{Adaptation ladder}

GlobalSA and LocalSA use identical random initial weights within each seed; only
their attention windows differ. Every converted PRA regime starts from that
seed's trained LocalSA checkpoint.

\begin{enumerate}[leftmargin=*]
\item \textbf{Frozen}: conversion only; no trainable parameters.
\item \textbf{Consumer LoRA}: low-rank updates to PRA Q/O and the immediately
following FFNs.
\item \textbf{Interface LoRA}: Consumer LoRA plus PRA K/V.
\item \textbf{Broad LoRA}: low-rank updates to every decoder linear module.
\item \textbf{Full weight}: all converted-model parameters continue training.
\item \textbf{Native scratch}: the same PRA topology is present from
initialization and all weights train end to end.
\end{enumerate}

LoRA rank is eight with scale $\alpha/r=2$. Baselines train for 800 steps;
converted trainable regimes continue for 500; native scratch trains for the
matched total of 1,300. We use five fixed model seeds, 4,096 deterministic
training examples, and 512 held-out examples. The objective is answer-token cross
entropy. No held-out result selects a checkpoint.

\subsection{Causal interventions and metrics}

For answer token $y$ and final logits $z$, define the margin
\begin{equation}
m = z_y - \max_{v\ne y} z_v.
\end{equation}
The primary usefulness effect compares correct and equally sized incorrect
memory:
\begin{equation}
G_m = m_{\mathrm{evidence}} - m_{\mathrm{matched\ distractor}}.
\end{equation}
We also report no-memory, evidence-only, and whole-parent conditions. Memory
modularity is measured by
\begin{equation}
\Delta\mathrm{NLL}=
\mathrm{NLL}_{\mathrm{evidence}}-\mathrm{NLL}_{\mathrm{parent}},
\end{equation}
with analogous accuracy and margin differences. Evidence selectivity is evidence
attention mass divided by total memory attention mass in the whole-parent
condition.

To test whether memory objects become less dependent on neighboring facts, we
encode the same evidence tokens alone and in the whole parent. At PRA-facing layer
$\ell$, key portability is
\begin{equation}
D_K^{(\ell)} = 1-\cos\!\left(K_{e,\mathrm{alone}}^{(\ell)},
K_{e,\mathrm{parent}}^{(\ell)}\right),
\end{equation}
averaged over heads, tokens, examples, and seeds; values are measured likewise.

\subsection{Adaptation capacity and causal usefulness}

improvement over Frozen is \PaperFourBestMarginEffect{} for

\subsection{Memory modularity and layer specialization}

Whole-parent accuracy also improves: Frozen reaches
\PaperFourFrozenParentAccuracy{}, while Consumer, Interface, Broad, Full, and
Native reach \PaperFourConsumerParentAccuracy{}/\PaperFourInterfaceParentAccuracy{}/
\PaperFourBroadParentAccuracy{}/\PaperFourFullParentAccuracy{}/
\PaperFourNativeParentAccuracy{}. This is a real noisy-memory gain, but it is much
smaller than the evidence-only gain. No regime reduces the absolute
evidence-versus-parent NLL gap; the least unfavorable change is
\PaperFourBestModularityEffect{} under \PaperFourBestModularityRegime{}. Gate 0
therefore rejects the strong modularity hypothesis. Whole-parent attention
provides a stricter view:
an adapted consumer should allocate its fixed memory mass to evidence rather than
merely increase attention to every imported token. The strongest paired
selectivity change is \PaperFourBestSelectivityEffect{} for
\PaperFourBestSelectivityRegime{}. It has the same direction in all seeds but is
small in magnitude. Adaptation mainly changes what the network can do with clean
memory; it does not yet create a strong token-level filter among distractors.

\subsection{Retention and chain depth}

Converted LoRA models largely retain the original no-memory full-context path.
Accuracy is \PaperFourFrozenRetention{} Frozen,
\PaperFourConsumerRetention{} Consumer, \PaperFourInterfaceRetention{} Interface,
and \PaperFourBroadRetention{} Broad. Full-weight continuation reaches
\PaperFourFullRetention{}. Native scratch reaches only
\PaperFourNativeRetention{} because it was trained through the sparse-memory path
rather than the original full-context interface. The strongest oracle ceiling is
therefore not the safest direct replacement for a pretrained model.

Evidence-only accuracy remains high through the four-hop stratum: Full and Native
both reach \PaperFourFullDepthFour{} and \PaperFourNativeDepthFour{}, respectively.
We do not interpret the upward shape of some curves as a causal depth benefit.
Each stratum is a different randomized sample, and the generator was designed to
prevent label leakage rather than calibrate equal difficulty by depth.

\subsection{Representation portability}

Figure~\ref{fig:portability} measures a different property from output quality.
A low value means the same evidence token produces similar keys when encoded alone
or amid distractors. A regime can improve answer use without making keys portable,
or make keys portable without teaching downstream layers to interpret values.
Reporting both prevents an output-only explanation from being mistaken for a
representation result.

\subsection{Gate decision}

The native-scratch evidence-memory accuracy minus LocalSA full-context accuracy is
\PaperFourNativeMinusLocalAccuracy{} on average. In total,
\PaperFourCriteriaPassed{} preregistered signals pass, producing
\texttt{\PaperFourGateDecision}. With five paired seeds, these results remain
descriptive: even a same-direction effect in all seeds has a minimum exact
two-sided sign-flip $p=0.0625$. We therefore use the gate to decide the next
experiment, not to claim a population-level scaling law.

\section{Tier 1: Pretrained Ordinary-Language Gate}

The first pretrained tier uses the 135M-parameter SmolLM2 checkpoint and the
WikiText-2 reference corpus. Oracle evidence identity remains fixed, preserving
the separation between consumption and discovery. Each of five deterministic
train/validation splits runs 100 steps with ordinary full-context rehearsal
every fourth step and evaluates 32 held-out continuations under no memory,
matched distractor, selected evidence, whole-parent memory, and ordinary
visible-context conditions. Consumer LoRA exposes 483,840 parameters at one
PRA slot per four blocks; Interface LoRA adds K/V projections for 569,856
trainable parameters.

Both adaptation scopes optimize successfully. Mean evidence NLL falls by
0.618 for Consumer and 0.636 for Interface, while ordinary visible-context NLL
also improves rather than regresses. The differentiable native-memory path is
active rather than nominal: mean maximum K/V gradient norm is zero for
Consumer by construction and 6.837 for Interface. Query/output and MLP
gradients are nonzero in both regimes.

The stricter causal gate does not yet pass. Evidence has lower NLL than the
matched distractor in four of five seeds for both adaptation scopes, with mean
margins of 0.0468 and 0.0472 nats. On seed 71 the signs reverse slightly
($-0.0128$ and $-0.0154$). The large before/after gain therefore includes
general continuation learning and cannot by itself establish replicated
reference-specific consumption. With five seeds, a same-direction result
would in any case have a minimum exact two-sided sign-flip $p=0.0625$.
Learned routing remains disabled until a harder causal task produces a
positive matched-distractor margin in every preregistered split.

\section{Related Work}

Sparse-attention methods reduce which token pairs interact inside a sequence
\cite{beltagy2020longformer,zaheer2020bigbird,roy2021routing}. Recurrent and
compressed-memory transformers carry state across segments
\cite{dai2019transformerxl,rae2020compressive}; Memorizing Transformers retrieve
stored representations \cite{wu2022memorizing}. PRA differs in separating compact
routing metadata from full-detail, layer-native K/V materialized under a bounded
operation. This paper studies the learning interface after selection rather than
proposing another retrieval score.

Retrieval-augmented language models train retrieval and generation jointly or in
coordinated stages \cite{guu2020realm,lewis2020rag,borgeaud2022retro}. Our oracle
stage is intentionally simpler. It provides a causal upper-bound question: if the
correct physical memory is already present, can adaptation make it useful? A
negative answer would make router optimization premature; a positive answer
justifies reconnecting learned routing at the next gate.

\section{Limitations and Next Gate}

Tier 0 uses a controlled vocabulary, answer-only objective, sub-million-parameter
model, and short schedule. Tier 1 adds pretrained ordinary text, but remains a
short continuation experiment rather than broad language-model evaluation.
Oracle memory removes identity errors in both tiers and does not test top-$k$
recall, graph traversal, or materialization budgets. The reported attention
masses are correlates of use; the matched-distractor margin is the stronger
causal output control. We do not measure production throughput because
references remain in the training graph.

Tier 1 adds an ordinary-language objective and a pretrained model below 0.5B
parameters. It validates the optimization path but misses the stricter
all-seed causal criterion: both Consumer and Interface LoRA produce a positive
evidence-versus-distractor margin in four of five splits. The next experiment
therefore hardens the continuation task and repeats these two scopes before
learning a router. If that causal margin replicates, routing advances with
shuffled, disabled, and oracle controls. Native scratch remains a ceiling and
a separate architecture-training question. Gemma-scale continuation remains a
later gate, not a direct consequence of either the toy or 135M result.

\section{Conclusion}

Sparse memory has two learning problems: finding the right state and making that
state computationally useful. By fixing the first, this study measures the second
directly. The differentiable native-KV path and matched adaptation ladder turn a
previously ambiguous frozen result into a testable training question. The toy
outcome and pretrained optimization result support a stage-gated program, but
the adverse causal split shows why optimization gain is not the same as
reference-specific learning. Consumer plasticity must clear that causal gate
before router complexity and model scale are increased.
