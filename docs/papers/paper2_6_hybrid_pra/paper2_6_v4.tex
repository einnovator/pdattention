\title{Multi-Representational Reference Discovery for Progressive Retrieval Attention:\\Semantic, Lexical, and Iterative Routing Across Four Evidence Tasks}
\author{Jorge Simao\\EInnovator R\&D -- Center for the Sciences of Computation, Cognition, and Complexity}
\date{\today}
\begin{document}\maketitle

\begin{abstract}
Progressive Retrieval Attention (PRA) separates a large logical memory from the smaller native-key/value working set admitted to attention. We study how PRA discovers that set using contextual semantic gists, exact and approximate model-token matching, BM25, token $n$-grams, and hybrid traversal. In the original four-dataset Qwen study, root and successor preferences differ on three datasets, while static score and rank fusion do not beat the best fixed channels. We then implement posting-list candidate narrowing and reproduce exhaustive top-four results for every paired query under both Qwen and SmolLM tokenizers. At 4,096 chunks, exact lookup is 283--300$\times$ faster than exhaustive Python scoring; fuzzy cascades are 56--64$\times$ faster but remain too slow for serving. A fresh Gate B confirmation uses 20 validation and 50 held-out identities per dataset, two frozen model families, four chunks/128 native-K/V tokens, five selector seeds, and complete causal controls. Channel geometry replicates: BM25 leads Hotpot recall (0.665/0.662), while approximate matching leads QASPER (0.747/0.783). Hotpot memory yields resolved gold-answer likelihood gains for both models, and the oracle beats irrelevant memory on both datasets and models. QASPER fixed-channel gains over disabled memory remain unresolved, and generated EM/F1 remains weak. Observable selection and referential calibration do not close these gaps. The supported result is therefore an indexed, portable discovery mechanism with causal native-K/V evidence on Hotpot, not a general QA improvement.
\end{abstract}

\section{Introduction}
PRA treats long context as addressable logical memory rather than a token sequence that must remain fully active~\cite{simao2026position,simao2026pra}. The system must find a tiny conceptual working set before a separate materializer decides which native K/V can participate in attention. Its native-KV design therefore separates stable object identity, compact routing representations, and detailed layer-specific state. This raises a distinct question: \emph{what evidence should discover a candidate memory object?}

Current routing can score a contextual query $q_{t,\ell}$ against chunk gist $g_{i,\ell}$:
\[
s^{sem}_{i,\ell}=\cos(q_{t,\ell},g_{i,\ell}).
\]
This captures contextual relatedness but need not preserve exact sequence identity. PRA, however, already has access to the host model tokenizer. Exact token spans, BM25-weighted terms, ordered token subsequences, and approximate subword matches recover evidence that semantic routing misses. They do not reliably resolve paraphrases, implicit relations, or ambiguous names, so contextual gists remain necessary. The four datasets below do not yield one winning formula, and static fusion does not dominate. More importantly, the best representation often changes after a root chunk enters the state and exposes a successor address. Retrieval representation is therefore a state-dependent control decision, with separate root action $S_{root}$ and successor action $S_{succ}$.

Paper~2 establishes the frozen-backbone native-K/V integration and identifies routing as the bottleneck~\cite{simao2026hf}. Paper~2.5 studies bounded associative discovery and exposes entry-routing, topology, granularity, and interference limits~\cite{simao2026iterative}. This paper asks which representations should generate and rank root and successor candidates. Paper~3 separately asks which discovered candidates, and how much detail, should be materialized~\cite{simao2026materialization}. Keeping discovery and physical participation separate is central to the experimental design.

\section{Hybrid Reference Discovery}
At hop $h$, let
\[
\mathcal C_h =
\mathcal C_h^{explicit}\cup
\mathcal C_h^{tok\mbox{-}exact}\cup
\mathcal C_h^{tok\mbox{-}approx}\cup
\mathcal C_h^{semantic}\cup
\mathcal C_h^{assoc}.
\]
Candidates retain URI/chunk identity, layer, raw channel scores, discovery hop, parent, provenance, rank, confidence, and an explicit calibration-status flag. Exact handles may resolve deterministically; approximate channels generate candidates.

An application can also pass stable reference handles with a generation request. The model validates those URIs against its registered reference cache and forwards the resolved URI set to every routing hop. Matching rows receive deterministic priority with provenance \texttt{explicit\_reference}; unknown handles fail before generation. This is product wiring rather than an oracle: the caller must possess the URI, and no evidence annotation enters the resolver.

The implementation compares a progressive resolution cascade, candidate union, score fusion, token-native scoring followed by semantic reranking, semantic scoring followed by token-native reranking, and iterative hybrid traversal. Classical BM25 over decoded word terms is retained as a strong baseline rather than absorbed into the proposed mechanism.

\section{Token-Native Reference Matching}
The proposed non-neural resolver operates over the host model tokenizer. For each memory object we retain raw token IDs, normalized token spans, decoded subword strings, and title/name/alias boundaries. This permits exact identity matching without a second NLP vocabulary, while still allowing controlled normalization of tokenizer-specific leading-space, punctuation, and case artifacts.

A progressive cascade is evaluated:
\[
\mathrm{explicit}
\rightarrow
\mathrm{exact\ token\ span}
\rightarrow
\mathrm{weighted/ordered\ token}
\rightarrow
\mathrm{approximate\ token}
\rightarrow
\mathrm{semantic\ gist}.
\]
Earlier high-confidence stages may resolve or sharply narrow candidates before later stages run.

For weighted overlap, let $Q$ and $R_i$ denote query and reference token multisets or aligned spans, and let $w(t)$ be a corpus-dependent token weight. A simple form is
\[
s_i^{overlap}
=
\frac{\sum_{t\in \mathrm{uniq}(Q)\cap \mathrm{uniq}(R_i)} w(t)}
{\sum_{t\in \mathrm{uniq}(R_i)} w(t)}.
\]
The present token-native score uses token-space inverse document frequency,
\[
w(t)=\log\frac{N+1}{df(t)+1},
\]
which can automatically downweight domain-generic tokens. Ordered subsequence overlap preserves multi-token identity while tolerating intervening material. A fixed stop list can instead remove common function words before retrieval. Token $n$-gram posting lists preserve local order without requiring an exact full-span match.

Approximate matching is attempted only after exact or high-confidence matching fails or remains ambiguous. Character-trigram postings first narrow the candidate set; sequence similarity is then evaluated only in that pool. Two additional diagnostic channels use bounded token edit distance over short subspans and cosine similarity between mean host-model input embeddings. The latter reuses the model's own embedding matrix rather than adding an independently trained representation. These channels are available for measurement, but are not silently folded into the product default.

\subsection{Indexed Candidate Generation}
Exhaustive scoring obscures the systems question because every query pays for every logical chunk. The production sidecar therefore stores postings for raw token IDs, normalized pieces, token $n$-grams, BM25 terms, character trigrams, and explicit reference URIs. A query forms the deduplicated union
\[
\mathcal U(q)=\mathcal P_{tok}(q)\cup\mathcal P_{ngram}(q)
\cup\mathcal P_{bm25}(q)\cup\mathcal P_{char}(q)
\cup\mathcal P_{uri}(q),
\]
then applies the requested channel only to rows in $\mathcal U(q)$, capped by a fixed candidate-pool budget. Semantic routing remains a tensor operation over gist states; indexed lexical retrieval narrows the token-native work. Channel unions deduplicate stable row identities before ranking.

Index extension is immutable: adding references rebuilds corpus document frequencies and row-aligned postings and returns a new sidecar. This costs more than an in-place append, but prevents stale IDF statistics and lets concurrent readers retain a consistent snapshot. We consequently report construction, warm-query, memory, and update costs separately.

Classical word-level BM25 remains a strong baseline~\cite{robertson2009bm25}. Approximate string matching is likewise a mature field~\cite{navarro2001approx}. The scientific question is whether these representations complement native semantic gists inside PRA's stateful discovery process, not whether conventional information retrieval is unnecessary.


\subsection{Confidence and Provenance}
A candidate record includes raw channel scores and an explicit confidence field with stable intended semantics:
\[
c_i \approx
P(r_i\ \mathrm{is\ a\ valid\ referent}\mid q,\mathbf{s}_i,p_i),
\]
where $\mathbf{s}_i$ contains channel-specific evidence and $p_i$ records discovery provenance. The same numerical score from an exact token match, an approximate token match, and a semantic gist is not assumed to have the same reliability.

Raw discovery scores are marked uncalibrated in runtime traces. We fit calibration only on validation candidates and evaluate Brier score, expected calibration error, reliability, and selective accuracy/coverage. This makes the discovery interface testable for subsequent control:
\[
c_i > \tau_{\mathrm{act}}
\Rightarrow \mathrm{materialize},
\]
\[
\tau_{\mathrm{search}} < c_i \le \tau_{\mathrm{act}}
\Rightarrow \mathrm{retrieve/disambiguate\ further},
\]
with low-confidence cases eligible for abstention. External side-effecting action remains outside the scope of this paper, but the same confidence semantics can later support act/search/ask/abstain policies in agent systems.

\section{Multi-Hop Reference Following}
A useful pattern is
\[
Q \xrightarrow{semantic} C_1
\xrightarrow{token\ reference} C_2
\xrightarrow{reasoning} A.
\]
After selecting $C_1$, its indexed token sequence becomes the lexical query for the next bounded hop. Its semantic gist remains the semantic frontier. Both channels therefore score the same aligned candidate rows before the existing branch, beam, depth, and unique-chunk controls admit $C_2$. This produces a dynamically traversed chunk--reference graph without requiring a complete symbolic knowledge graph in advance.

If reference structure is informative, sparse traversal may replace broad semantic expansion:
\[
\mathrm{same\ evidence\ recall}
\quad\text{with}\quad
\mathrm{fewer\ candidates/materialized\ tokens}.
\]

\section{Research Questions and Success Levels}
\begin{enumerate}[leftmargin=*]
\item Does hybrid discovery improve supporting-evidence recall at matched active budget?
\item Which discovery signals dominate entry versus later hops?
\item Can iterative reference following outperform simply increasing semantic top-$k$?
\item Do candidate provenance and confidence improve downstream materialization/control decisions?
\item When does token-level reference structure fail to add value over contextual gists?
\item Do retrieval improvements survive end-to-end answer generation?
\end{enumerate}

We distinguish two success levels. A \emph{discovery-level positive result} requires improved required-evidence recall at matched active cost, or matched recall with materially lower active memory/cost, supported statistically and by causal controls. An \emph{end-to-end positive result} additionally requires a resolved improvement in downstream QA, such as paired EM/F1 improvement with an appropriate confidence interval or significance test on at least one natural multi-hop dataset.

This distinction is essential. A robust discovery Pareto improvement remains scientifically meaningful independently of whether a frozen consumer converts it into answer gains. Gate B tests that conversion separately; retrieval recall is never described as improved reasoning or QA performance.


\section{Tokenization Robustness}
Token-native matching introduces a specific invariance question: can the resolver recognize the same referent when its surface form induces a different tokenizer sequence? We therefore make tokenization robustness a first-class experiment rather than a minor tokenizer-family ablation.

For a fixed referent $r$, construct controlled variants
\[
\mathcal P(r)=
\{r_{\mathrm{case}},r_{\mathrm{space}},r_{\mathrm{punct}},
r_{\mathrm{hyphen}},r_{\mathrm{split}},r_{\mathrm{typo}},
r_{\mathrm{abbr}},r_{\mathrm{alias}},\ldots\}.
\]
The expanded controlled suite covers case, punctuation, leading-space artifacts, whitespace splitting, hyphenation, concatenation, one-character misspellings, abbreviations, aliases, full-width Unicode and mathematical-letter compatibility forms, near entities, shared prefixes, numeric identifiers, URL/domain overlap, same-name and same-class ambiguity, wrong relations, stale aliases, two plausible references, and contradictory high-overlap names. Normalization uses Unicode NFKC before case folding. Conservative aliases are extracted automatically from headings and parenthetical names; application-supplied aliases remain available when a stronger entity registry exists.

We measure degradation separately for exact-span, weighted/ordered, approximate-token, cascade, and iterative-hybrid conditions. The objective is an invariance curve showing how rapidly each mechanism loses referent accuracy as the surface form moves away from exact token identity.

\section{Wrong-Reference Stress Testing}
Average recall is insufficient if token-native matching becomes confidently wrong under ambiguity. We implement controlled conflicts in which an admitted chunk exposes a high-overlap distractor, a stale alias, an instance of the right class, the right entity under the wrong relation, or two lexically plausible referents. These are deterministic mechanism fixtures, not a claim that entity resolution is solved.

A particularly diagnostic condition is
\[
s_{\mathrm{token}}(A) \gg s_{\mathrm{token}}(B),
\qquad
s_{\mathrm{semantic}}(B) \gg s_{\mathrm{semantic}}(A),
\]
with only one candidate being the valid referent. The controlled test measures wrong-candidate confidence and target recovery after the conflicting hop. Gate B adds naturally occurring top-choice errors, validation-only selective calibration, and wrong-memory generation controls, but it is not a curated natural same-name coreference corpus. A useful hybrid method should degrade gracefully rather than convert ambiguous token evidence into high-confidence catastrophic routing errors.

\section{Experimental Protocol}
\subsection{Controlled Mechanism Tasks}
We construct 20 deterministic chains per condition. A semantic entry identifies the first chunk, which exposes a token address for a target placed behind two stronger semantic distractors. Fifteen surface-form and referential conditions use the same two-chunk request budget and the same candidate layout. These are mechanism probes, not independent natural examples.

\subsection{Natural Evidence Retrieval}
We reuse the identity-disjoint Paper~2 feature protocol: frozen Qwen3-0.6B attention-input hidden states at layer 27, 32-token mean-gist chunks, revision \texttt{c1899de...e47ca}, and the question-exponential query. Validation contains eight HotpotQA and eight QASPER examples; held-out test contains 16 of each. No model weights are loaded in this study. B0--B4 and H1--H5 receive a final budget of four requested chunks. A1 deliberately buys breadth with eight semantic chunks and is not a matched-budget result. O1 admits annotated evidence first as a ceiling. No candidate is materialized.

The hybrid entry/later semantic weights are selected on validation from $\{0.4,0.6,0.8\}\times\{0.1,0.3,0.5\}$, with token weights as complements. Entry weights 0.4 and 0.6 tie in aggregate validation recall; the semantic-entry/token-later tie-break selects $(0.6,0.1)$. Test identities are not used for selection. Confidence uses a monotone ten-bin histogram fitted only on validation candidates.

The extension reuses Paper~2.5's separately frozen natural-graph cohort: 24 validation and 24 test 2Wiki examples, plus 18 validation and 18 test MuSiQue examples. Labelled evidence spans map through the fast tokenizer before the routing partition is constructed. Frozen token hidden states are averaged over the same 32-token local spans, yielding one gist per candidate chunk; the question-exponential query and layer remain unchanged. Six primary channels---gist, exact, BM25, approximate token, static token-to-semantic reranking, and two-hop iterative hybrid---all request exactly four unique chunks. Iteration uses branch two per step, depth two, at most four unique chunks, and reports all comparisons. The $(0.6,0.1)$ entry/later semantic weights are inherited without retuning. These cohorts remain below the requested 50 held-out units per dataset, so all new comparisons are explicitly cohort-bounded.

Per-example explanatory geometry includes query/evidence token overlap, IDF-weighted overlap, named-entity overlap, evidence regions, evidence extent and gaps, annotated depth, root ranks, score gaps, and channel disagreement. Gold-derived geometry is never passed to the adaptive baseline. Its fixed rule can see query rarity, root score gaps, channel disagreement, and whether an already admitted hop-one chunk exposes a rare address. The selector API rejects gold fields. Best fixed channels are selected on validation; the per-example oracle is evaluated only as an upper bound.

\subsection{Channel Selection and Iterative Exposure}
The per-example channel oracle reaches recall 0.207 on QASPER, 0.489 on Hotpot, 0.315 on 2Wiki, and 0.199 on MuSiQue. Relative to the channel selected on validation, mean oracle headroom is 0.029, 0.338, 0.130, and 0.067. Hotpot's large value partly reflects validation instability: gist beats BM25 by only 0.001 on eight validation examples, whereas BM25 is much stronger on test. On 2Wiki, validation selects iterative hybrid while test favors BM25. These reversals are evidence for larger calibration cohorts, not evidence that test labels should choose a production channel.

The fixed observable selector does not realize the oracle opportunity. Its recall is 0.081, 0.279, 0.186, and 0.146 across QASPER, Hotpot, 2Wiki, and MuSiQue. It therefore improves over static hybrid only on QASPER, ties the iterative policy elsewhere by construction, and remains below the best held-out single channel. We retain it as a leakage-audited baseline, not as the proposed final policy. A learned selector requires a larger validation cohort and should predict channel utility from query rarity, calibrated score gaps, and disagreement without using answer or evidence annotations.

A stricter new-address metric requires a normalized tokenizer piece to be absent from the question, present in an admitted hop-one chunk and unrecovered gold evidence, and rare under the example-local IDF. Such addresses occur in 6/16 QASPER, 5/16 Hotpot, 10/24 2Wiki, and 15/18 MuSiQue cases. Iterative-minus-static recall on address-positive cases is +0.100, $-0.047$, $-0.005$, and +0.003, respectively; address-negative effects are 0.000, +0.010, $-0.027$, and $-0.042$. Exposure is therefore necessary for the controlled lexical-following mechanism but not sufficient on natural data. The router must also identify the right address, preserve the right frontier, and rank the successor within the same total budget.

The successor headline holds the root policy fixed to the validation-selected channel, so successor quality is not averaged over changing root quality. For MuSiQue and 2Wiki, successor truth follows annotated dependency nodes; QASPER and Hotpot lack an ordered graph annotation, so successor truth is explicitly labelled as the remaining unordered evidence. This distinction prevents an inferred chain from becoming dataset truth.

\subsection{True Headroom and Observable Selection}
We decompose oracle gain as
\[
H_{selection}=R_{oracle}-R_{best\ heldout\ fixed},\qquad
H_{validation}=R_{best\ heldout\ fixed}-R_{validation\ selected}.
\]
Mean $H_{selection}$ is 0.014 on QASPER, 0.021 on Hotpot, 0.053 on 2Wiki, and 0.013 on MuSiQue. Mean $H_{validation}$ is 0, 0.031, 0.026, and 0. This corrects the earlier four-chunk ``oracle headroom'' figure, which combined adaptive opportunity with small-validation reversal. At the two-chunk root stage, 2Wiki has the largest true adaptive opportunity, while Hotpot's validation instability is larger than its true selector headroom.

With the validation root held fixed, successor $H_{selection}$ is 0.027, 0.028, 0.056, and 0.016; successor $H_{validation}$ is 0, 0.056, 0.011, and 0.008. Thus 2Wiki retains the largest true channel opportunity at both stages, while Hotpot's successor-channel validation reversal is twice its true adaptive headroom. The action space is real, but these small calibration splits cannot choose it reliably.

Neither modest selector baseline closes the gap. The fixed hand rule reaches root recall 0.020, 0.031, 0.040, and 0.073 across QASPER, Hotpot, 2Wiki, and MuSiQue. A validation-trained linear softmax selector over 24 query-only and score/rank features reaches 0.047, 0.016, 0.053, and 0.084. The best held-out fixed channels reach 0.096, 0.047, 0.076, and 0.084; the per-example oracle reaches 0.110, 0.068, 0.130, and 0.096. The linear model ties the fixed MuSiQue result and improves over the validation-selected 2Wiki channel by 0.003, but it does not justify replacing a fixed policy. No MLP is fitted because the 58 validation identities do not support a larger controller.

Root-channel disagreement also fails as a standalone selector feature. Its Pearson correlation with true per-example oracle headroom is only 0.052; selected-set Jaccard, top-10 rank overlap, and score disagreement have correlations 0.020, 0.107, and 0.013. Disagreement reveals representation diversity, but diversity alone does not say which channel is right.

\subsection{Why Static Fusion Loses}
At a two-chunk root budget, lexical channels add unique gold chunks relative to gist---0.812 per QASPER example, 0.188 Hotpot, 0.208 2Wiki, and 0.333 MuSiQue---but simultaneously add 3.062, 3.500, 2.792, and 2.778 unique distractors. Static hybrid recall is 0.031, 0.031, 0.053, and 0.082, below the per-example best single-channel recall of 0.110, 0.068, 0.130, and 0.087. The failure is therefore budget dilution plus score-scale mismatch, not lack of complementary evidence. Reciprocal-rank fusion avoids raw-score calibration assumptions but reaches only 0.035, 0.044, 0.053, and 0.045 recall. It is not a hidden robust winner.

\subsection{Useful Addresses and Robustness}
We tighten the iterative condition to
\[
\mathrm{UsefulAddress}=\mathrm{Exposed}\land\mathrm{GoldLinked}\land
(\mathrm{successor\ rank}\leq4).
\]
Under validation-selected roots, useful-address rates are 0.250 on QASPER, 0.063 on Hotpot, 0 on the 18 successor-bearing 2Wiki examples, and 0.222 on MuSiQue. UsefulAddress predicts a positive hybrid-state versus native-semantic path effect only on MuSiQue: +0.054 versus $-0.001$ without a useful address. QASPER is $-0.021$ in both strata; the single useful Hotpot case ties, and no 2Wiki address is competitive. Rare exposure is thus insufficient until the address also ranks within retry reach, and even the stricter predicate is dataset-dependent.

\section{Final Stability and Referential-Validity Diagnostics}
\subsection{Cohort Feasibility and Selection Stability}
The frozen study contains 132 identities: 58 validation and 74 held out. The held-out composition is 16 QASPER, 16 HotpotQA, 24 2Wiki, and 18 MuSiQue identities. We sought a cheap expansion to at least 50 identities per dataset, but no larger identity-compatible feature capture exists for the fixed model revision, layer, chunking, evidence map, and query aggregation. New hidden-state extraction would change the provenance of this final iteration. We therefore retain all 132 identities and report 1,000 deterministic, identity-paired bootstrap resamples at increasing cohort sizes. Resamples estimate uncertainty; they are not new examples.

At each dataset's full held-out size, QASPER chooses exact root search in 94.3\% of resamples. Hotpot chooses exact in 60.6\%, with BM25 at 23.1\% and semantic at 15.3\%. 2Wiki chooses semantic in 66.6\%. MuSiQue remains unresolved: approximate wins 36.8\%, hybrid 35.4\%, and BM25 24.8\%. Successor selection is most stable for Hotpot native semantic (93.2\%). QASPER splits between exact-new-address (57.7\%) and native semantic (38.3\%); 2Wiki splits among exact-new-address (47.8\%), hybrid-state (26.4\%), and native semantic (25.2\%); MuSiQue splits between native semantic (59.0\%) and BM25-state (34.3\%). Thus the three-of-four root/successor mismatch survives resampling, but several channel labels should be read as cohort preferences rather than settled rankings.

\subsection{Match Confidence Is Not Referential Validity}
The replay exports 1,255 candidate-level confidence rows without changing any route. Signals include top score, top-1/top-2 gap, score entropy and effective support, exact span length, matched-token rarity and occurrence count, approximate similarity, ambiguity count, alias indication, cross-channel agreement, semantic consistency, current-path consistency, and source consistency. Gold membership is added only as the evaluation outcome. Dataset identity, answer text, evidence geometry, and oracle labels are forbidden selector inputs.

Validation-CDF calibration does not turn these signals into reliable referential probabilities. For the composite referential-consistency proxy, root-channel AUROC ranges from .353 to .605 and averages .424; successor-channel AUROC ranges from .396 to .717 and averages .526. Mean AUPRC is .105 at root and .156 at successor, while mean ECE is .401 and .456. The apparently stronger BM25-state AUROC (.717) is based on only four positive top-1 successors among 68 held-out identities and does not support a general calibration claim. Score strength and referential validity remain different quantities.

\subsection{Ambiguity, Abstention, and Useful Addresses}
The expanded controlled suite preserves the clean, case, punctuation, typo, alias, near-entity, shared-prefix, numeric-ID, URL, and confidently-wrong conditions and adds five referential conflicts. Stale aliases route to the wrong target in every trial for exact, approximate, and hybrid search. A same-class wrong instance is selected in every approximate trial and half of exact and hybrid trials. Under the correct-entity/wrong-relation fixture, approximate search splits evenly between valid and wrong targets; exact and hybrid recover neither. Two plausible references happen to select the valid candidate because of deterministic tie order, which demonstrates neither disambiguation nor robustness. \subsection{Native-K/V Gate B Protocol}
The confirmation uses two frozen model/tokenizer families and identities that are disjoint from the original 24-example-per-dataset Paper~2.6 cohort. For each model, 20 new examples per dataset tune only the observable channel selector, and 50 further examples per dataset form the held-out test. A serialized audit confirms zero pairwise overlap among the 48 legacy, 40 validation, 100 test, and 16 interaction identities. For this mechanism check, annotated evidence strings are placed first, followed by the original source, and the result is bounded to 1,536 tokens. Gold labels are not passed to any learned or fixed channel, but this construction is annotation dependent and is not an unmodified QA benchmark. The bounded source is partitioned into 32-token chunks, and all routed conditions receive four chunks and at most 128 physical native-K/V tokens across four late consumption layers. Semantic, exact, BM25, approximate, hybrid, a five-seed validation-trained selector, and a padded evidence oracle share this budget.

Generation controls hold the prompt and frozen model fixed: disabled and empty use no memory; shuffled uses the selected budget from another location; irrelevant uses non-evidence chunks; and bounded direct context places the same bounded source in the ordinary prompt. We report evidence recall/precision, EM, token F1, mean gold-answer token log probability, generation time, physical K/V counts, and paired bootstrap intervals. The oracle is an annotated diagnostic ceiling and never participates in channel training.

The oracle still beats irrelevant memory by 0.154 [0.074, 0.231] and 0.091 [0.033, 0.150], respectively. Thus the native-K/V mechanism discriminates correct from wrong memory, but no fixed QASPER channel establishes a benefit over no memory. This is a routing-to-consumption gap, not evidence that retrieval recall is false.

Physical accounting confirms the match. Routed conditions materialize 127.8--128.0 unique tokens, 8.33--9.36\% of the bounded source, at each of four late layers. Generated-answer EM/F1 does not provide a resolved positive result. Qwen Hotpot memory conditions reach EM 0.00--0.02 and F1 0.074--0.120; SmolLM EM is zero. Bounded direct context reaches Qwen Hotpot F1 0.183, but costs 5.28~s generation per example versus about 1.4~s for 128-token PRA memory. The corresponding SmolLM times are 2.63~s versus about 1.3~s. These tiny frozen models make teacher-forced likelihood the more sensitive causal measure; the paper does not relabel it as answer-quality improvement.

\subsection{Channel, Granularity, Budget, and Layer Interactions}
We next cross eight channels with 16-, 32-, and 64-token routing chunks; Top-2, Top-4, and Top-8 selection; and an early versus late routing layer. The fresh exploratory cohort contains eight HotpotQA and eight QASPER identities, disjoint from every legacy, validation, and Gate B test identity, for each model. The implementation makes each requested budget reachable by setting per-hop branch and beam width to 1, 2, and 4, respectively. The resulting 4,608 rows select exactly 2, 4, or 8 chunks in the corresponding condition. This explicit reachability check corrects a pilot in which Top-8 was silently capped by a narrower beam.

At 32-token chunks, increasing the physical budget gives a consistent coverage--precision exchange. Averaged over channels, late-layer Hotpot recall rises from 0.562 to 0.703 to 0.883 for Qwen and from 0.547 to 0.703 to 0.953 for SmolLM as the budget moves from two to four to eight chunks. Complete-evidence recovery rises from 0.406 to 0.562 to 0.812 and from 0.406 to 0.547 to 0.906, while precision falls from 0.414 to 0.229 and from 0.375 to 0.225. QASPER follows the same broad pattern: recall reaches 0.917 for Qwen and 0.943 for SmolLM at Top-8, but precision declines relative to Top-4. Breadth is therefore useful for evidence discovery, but it is not free selectivity.

\subsection{Natural Wrong-Reference Calibration}
Naturally annotated evidence spans label whether each channel's top chunk is relevant. Approximate top-one accuracy on Hotpot is 0.94 for both models, but falls to 0.36--0.40 on QASPER. Exact reaches 0.64 on Hotpot and 0.46--0.54 on QASPER; BM25 reaches 0.48--0.54 and 0.08. Validation-CDF thresholds chosen for at least 0.80 precision do not transfer: except for approximate Hotpot (0.94 precision), held-out precision remains below 0.64 and often below 0.20. Confidence continues to be a referential-validity problem even when recall is strong.

\section{Evaluation}
Discovery metrics include supporting-document/fact recall, MRR, NDCG, precision, missed-evidence rate, hop success, and path completion. Resource metrics include discovered, requested, and materialized chunks/tokens, active fraction, distractor materialization, index construction, cold/warm routing, repeated-hop cost, transfer, and end-to-end latency.

\subsection{Candidate-Normalized Discovery Efficiency}
Absolute Top-$K$ is not comparable across sources with different numbers of
chunks or evidence spans.  For each example, let $N$ be the number of candidate
chunks, $E$ the number of evaluator-labelled evidence chunks, and $K$ the
deduplicated selected set.  We report evidence recall
$R_E=|K\cap E|/|E|$, evidence precision $P_E=|K\cap E|/|K|$, complete recovery
$C_E=\mathbb{1}[E\subseteq K]$, selected fraction $\phi=K/N$, sparsity
$\rho=1-\phi$, and working-set overhead $\omega=K/E$.  For a successor route,
$K$ is the union of root and successor identities; thus duplicate selections do
not receive extra credit.  Search comparisons and token-span operations remain
separate costs, not proxies for physical K/V activation.

\section{Open Ablations and Controls}
This study covers the complete policy matrix, four natural discovery cohorts, matched primary budgets, raw and normalized exact spans, token $n$-grams, IDF and fixed-stop policies, bounded edit and host-embedding diagnostics, automatic aliases, two tokenizer/model families, per-example geometry, channel diversity, oracle headroom, a five-seed validation-trained selector, perturbations, natural and controlled wrong references, and provenance-aware calibration. The interaction experiment crosses channel with chunk size, chunk budget, and routing layer. It does not exhaust gist count, attention-layer count, models above 0.6B parameters, learned contextual entity linking, incremental index updates, or a substantially larger selector-training set. Those remain open rather than implied completed experiments.

Metadata must not leak gold supporting labels. The exact query text/state used by each channel and hop is logged. Discovery is not counted as materialization, and hybrid systems do not receive an unreported larger active budget.

\section{Interface to Materialization}
The implementation exposes the discovery-side equivalent of
\[
\mathrm{discover}(q,M,B,\pi)\rightarrow
\{(r_i,\mathbf{s}_i,p_i,c_i)\}_{i=1}^{n},
\]
where $\mathbf{s}_i$ preserves channel scores, $p_i$ provenance, and $c_i$ has the referent-validity semantics defined above. Paper 3 consumes these candidates and independently chooses an active native-KV set:
\[
\mathrm{materialize}(C,B_{KV},\pi_M)\rightarrow\mathcal A.
\]
Paper 3 can consume this record without making materialization depend on one retriever.

\section{Search-Method Action-Space Handoff}
The version-2 action specification,
\path{search_method_action_spec.json}, freezes five independent root actions:
\[
S_{root}\in\{\mathrm{semantic},\mathrm{exact},\mathrm{BM25},
\mathrm{approximate},\mathrm{hybrid}\},
\]
and five successor actions:
\[
S_{succ}\in\{\mathrm{native\ semantic},\mathrm{exact\ new\ address},
\mathrm{BM25\ state},\mathrm{approximate\ new\ address},
\mathrm{hybrid\ state}\}.
\]
Each entry names its implementation identifier, required state and indexes, legal parameters, confidence outputs, separate cost metrics, and known failure modes. Legacy channel names such as \texttt{gist} and \texttt{approx} remain explicit aliases rather than silently changing prior artifacts. The version-2 schema declares that root and successor choices are independent and records that its source experiment did not materialize K/V; the newer Gate B artifact records physical counts separately rather than rewriting that provenance.

Paper~2.6 establishes this search-method action space and its empirical heterogeneity. Paper~3.5 treats $S_{root}$ and $S_{succ}$ as adaptive actions jointly with query interpretation, breadth/depth, admission budgets, and bounded retry~\cite{simao2026adaptive}. The handoff exports observable confidence and abstention signals, but it does not import dataset identity or gold outcomes into the controller.

\section{Relation to the PRA Series}
The position paper separates a large logical address space from the finite active working set and frames activation as demand-driven virtual memory~\cite{simao2026position}. Paper~2.6 studies discovery over that logical memory. Paper~1 establishes model-bounded native-K/V mechanics~\cite{simao2026pra}; Paper~1.5 owns positional transport and relocation, which this study holds fixed. Paper~2 integrates frozen pretrained backbones and identifies routing, rather than K/V construction, as the limiting interface~\cite{simao2026hf}; the present work changes discovery representations without retraining the consumer.

The strongest conceptual link is Paper~2.5's associative-memory decomposition~\cite{simao2026iterative}. Query-to-root entry is often harder than memory-to-memory traversal, and admitted evidence can expose a new address. Paper~2.6 adds multiple retrieval representations for entering and traversing that topology. Paper~3 asks how discovered identities should be materialized at variable detail and budget~\cite{simao2026materialization}; Gate B holds one such contract fixed only to validate the discovery-to-consumption boundary. Paper~3.5 receives the method and confidence contract for adaptive selection. This paper does not claim that its diagnostic selector is that adaptive controller.

\section{Related Work}
\subsection{Retrieval-Augmented Attention and Long-Context Memory}
Dense passage retrieval and RAG select external text that a reader or generator subsequently consumes~\cite{karpukhin2020dpr,lewis2020rag}. RETRO retrieves neighboring text chunks into a trained decoder, while Memorizing Transformers query a non-differentiable memory of prior key/value representations~\cite{borgeaud2022retro,wu2022memorizing}. Query-aware sparse-attention systems operate closer to physical attention: Quest selects K/V pages from query-dependent bounds, and RetrievalAttention builds attention-aware vector indexes over K/V~\cite{tang2024quest,liu2025retrievalattention}. Paper~2.6 is primarily upstream of that physical choice: it compares representations for discovering identity-bearing PRA memory objects. Gate B then holds the inherited Paper~2 materializer fixed to test whether discovery differences survive native-K/V admission; policies for choosing how much detail to materialize remain Paper~3's subject.

\subsection{RAG, Sparse Retrieval, and Static Hybrid Fusion}
BM25 is a probabilistic sparse relevance model, whereas DPR learns dense passage similarity~\cite{robertson2009bm25,karpukhin2020dpr}. Combining sparse and dense candidates, reranking them, or fusing ranks is established information-retrieval practice; reciprocal-rank fusion is one simple score-scale-independent method~\cite{cormack2009rrf}. Hybrid IR itself is not the novelty here. The narrower question is whether exact, BM25, approximate, and hidden-state semantic representations occupy different regimes when they address identity-aligned PRA memory. The negative static-fusion and RRF results show that complementary candidates can dilute a two-chunk budget; they do not imply that hybrid retrieval is generally ineffective.

\subsection{Multi-Hop and State-Dependent Retrieval}
Multi-hop dense retrieval conditions a later retrieval step on an earlier passage~\cite{xiong2021mdr}. IRRR iteratively builds a reasoning path, generates the next search query, reranks evidence, and decides whether to continue~\cite{qi2021irrr}; IRCoT interleaves retrieval with generated reasoning~\cite{trivedi2023ircot}. These systems establish that retrieved evidence can change the next search state. PRA shares that state dependence but traverses identities aligned to reusable native-memory objects. Paper~2.6 further asks whether the representation itself should change between root entry and successor traversal.

\subsection{Entity and Approximate Reference Resolution}
Approximate string matching studies principled retrieval under insertions, deletions, substitutions, and related surface variation~\cite{navarro2001approx}. Entity linking addresses the harder problem of assigning a mention to the correct entity under ambiguity. BLINK, for example, retrieves entity descriptions with a bi-encoder and reranks mention--entity pairs with a cross-encoder~\cite{wu2020blink}. The present exact and approximate channels are intentionally lighter-weight. Their typo and alias gains coexist with stale-alias, wrong-instance, and wrong-relation failures. Contextual entity disambiguation is therefore a relevant future component, not a capability claimed by the current matcher.

\section{Contributions}
This work contributes: (1) a provenance-preserving, multi-representational discovery formulation for PRA; (2) a model-token-native matcher evaluated beside decoded-word BM25; (3) posting-list indexes for exact spans, token $n$-grams, BM25, approximate narrowing, aliases, and explicit URIs; (4) one bounded iterative engine shared by semantic, token, and hybrid policies; (5) a four-dataset, matched-budget precision--recall and root/successor analysis; (6) a two-tokenizer invariance and index-scaling study; (7) a fresh two-model, 100-held-out-identity Gate B confirmation through native-K/V materialization and generation; (8) complete matched-budget causal controls and natural wrong-reference calibration; (9) leakage-audited five-seed selectors and oracle-headroom analysis; and (10) a versioned root/successor action space for adaptive control and a clean identity-level handoff to materialization.

\section{Discussion}
\paragraph{Established.} PRA-native discovery is multi-representational and state dependent. Exact, BM25, approximate, and semantic channels each recover evidence missed by another representation; root and successor preferences differ on three of four original datasets; and neither static score fusion nor RRF dominates under the matched budget. Indexed token-native routing preserves exhaustive top-four results while sharply reducing scored candidates. Hotpot/QASPER channel geometry replicates across Qwen and SmolLM. Under frozen native-K/V consumption, Hotpot correct-memory likelihood gains are causal for both models; on QASPER, oracle-versus-irrelevant effects are resolved even though fixed-channel gains over disabled memory are not.

\paragraph{Unresolved.} Observable method selection, referential disambiguation, and routing-to-consumption transfer remain unsolved. Five controller seeds are stable but all remain below the best fixed channel. Validation-CDF selectivity does not transfer except for approximate Hotpot, and QASPER's high retrieval recall does not produce a fixed-channel likelihood gain. Contextual entity/relation resolution, stronger consumers, and unmodified full-document cohorts are needed before an adaptive policy can be trusted.

\paragraph{Handed off.} Paper~3.5 receives independent root and successor actions, observable confidence fields, failure indicators, and abstention opportunities. Paper~3 receives selected conceptual identities and independently controls physical K/V admission. Gate B measures one fixed materialization contract; it does not collapse discovery and materialization into one policy.

\section{Limitations and Falsification}
The original frozen natural study contains 132 identities, of which 74 are held out: 16 QASPER, 16 HotpotQA, 24 2Wiki, and 18 MuSiQue. Only 18 held-out 2Wiki examples have a distinct annotated successor under this partition. Its inherited feature cache remains one-model and cannot be enlarged without recapture. The confirmation adds 40 disjoint validation and 100 disjoint test identities, evaluated under both model families; the interaction cohort adds 16 more. Five seeds measure optimization sensitivity, not independent dataset samples.

The confirmation's evidence-first 1,536-token construction depends on gold spans to retain evidence and is therefore a mechanism experiment, not an unmodified QA benchmark. Only Qwen3-0.6B and SmolLM2-135M are tested; neither is a strong QA generator, and EM/F1 stays weak. The interaction crossing uses eight examples per dataset and is exploratory. QASPER and Hotpot successor labels are unordered evidence remainders rather than annotated dependency edges. Geometry strata are descriptive and partly gold-derived; they explain failures but cannot be controller inputs. Natural wrong-reference labels indicate evidence overlap rather than adjudicated entity-coreference correctness.

The index memory number is a payload estimate that excludes Python-object overhead. Updates rebuild full corpus statistics rather than append incrementally. Exact lookup is much faster than exhaustive scoring, but the 0.50--0.65~s fuzzy paths at 4,096 chunks remain too slow for serving claims. Validation-calibrated confidence does not transfer reliably, neither selector closes the oracle gap, and confidently wrong or stale references remain possible.

The end-to-end result is deliberately metric specific. Hotpot gold-answer likelihood improves causally, but generated EM/F1 does not. QASPER correct memory beats irrelevant memory at the oracle ceiling, yet no fixed channel beats disabled memory with a resolved interval. A stronger claim would require gains under unmodified documents, larger models, fresh datasets, and answer-quality metrics. Failure to reproduce indexed parity, cross-tokenizer channel ordering, or the paired correct-versus-wrong-memory effects would falsify the corresponding claims independently.

\section{Conclusion}
PRA discovery need not be one hidden-state similarity function. An identity-aligned token sidecar can participate in bounded gist traversal, use posting lists rather than exhaustive candidate scans, and pass selected identities into native-K/V materialization without changing the frozen consumer. Across four discovery cohorts, exact, BM25, approximate, and semantic channels occupy different regimes, and the preferred representation changes from root entry to successor traversal on three datasets. Across two fresh model/tokenizer families, BM25 again leads Hotpot retrieval and approximate matching leads QASPER.

The supported conclusion is architectural and operationally bounded. Retrieval representation should be exposed as a state-dependent action, with $S_{root}$ separate from $S_{succ}$. Hotpot shows that correctly discovered sparse memory can improve frozen-model answer likelihood after physical admission; QASPER shows why discovery recall cannot substitute for consumption evaluation. Until observable selectors, referential validity, and generated answer quality improve on larger unmodified cohorts, dataset-validated fixed policies, explicit references, abstention, and bounded retry are more defensible than a universal fusion rule.
