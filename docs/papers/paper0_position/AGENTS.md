# AGENTS.md — Paper 0

## Goal
Write a high-quality position paper arguing that long-context inference should move from flat token streams toward URI-addressed, hierarchical, demand-driven memory expansion.

## Main Contribution
Frame Progressive Retrieval Attention as a bridge between:
- long-context transformers
- retrieval-augmented generation
- coding-agent progressive disclosure
- KV-cache/runtime memory systems

## Must Cover
- Why brute-force long context is inefficient.
- Why one-shot RAG is often too shallow.
- Why agentic search is powerful but expensive.
- How reference handles and recursive anchors could internalize search-like behavior.
- Difference between PRA as architecture, runtime, and research program.

## Avoid
- Do not claim experimental superiority.
- Do not overstate implementation readiness.
- Mark all quantitative tables as conceptual or illustrative.

## Target
30–40 page position/survey paper.
