# Paper 7 inherited typed-record evidence

These files are frozen copies from commit
`c65e85cf30fa69e46cdb4428ae90afa49a077e11` on the Paper 7 branch, copied on
2026-08-28 for Paper 4.5 runtime integration.

They retain the Paper 7 protocol and evidence scope. Paper 4.5 uses them to
document inherited typed-record defaults; it does not merge them into the
layer-profile smoke cohort or relabel them as serving measurements.

- `headroom_pra_cost_frontier.csv`: visible-token and recovery accounting.
- `headroom_reverse_eval_hybrid.csv`: typed, BM25, embedding, and cheap-hybrid
  recall on the 24 eligible reverse-evaluation cases.
- `product_lifecycle_cost_table.csv`: lifecycle state and cost accounting.
- `manifest.json`: original cohort and fusion metadata.
