# Adaptive search-method claim audit

- The study replays frozen Paper 2.6 discovery rows; it does not rerun generation.
- Root and successor requests are two chunks each and are evaluated at matched budgets.
- Oracle labels select rows only in offline analysis and never enter deployment features.
- Dataset identity is metadata and is excluded from every learned selector.
- The Paper 3.5 factorized join reports both measured surfaces and a conservative floor; it is not an end-to-end joint execution.
- Paper 2.6 performs no K/V materialization. Search and K/V costs are not collapsed into a cross-system scalar.
