# Post-gate observation-receipt smoke

This is synthetic mechanism evidence, not autonomous task-success evidence.
Runs used Ollama 0.30.8 on the M5 16 GB host (`192.168.1.8`), `qwen3:14b`,
the exact `Qwen/Qwen3-14B` tokenizer, temperature zero, seed zero, and a
1,024-token output ceiling.

## Short-observation fail-closed controls

The compact receipt candidate was larger than the original observation in both
unchanged synthetic trajectories, so the size gate abstained and reinserted the
complete original causal group.

| Case | Source / candidate receipt tokens | Actual receipts / abstentions | Full / materialized tokens | Request equal to FULL | Content / command equal to FULL |
|---|---:|---:|---:|---:|---:|
| H1 old search | 26 / 43 | 0 / 1 | 393 / 393 | yes, byte-identical | yes / yes |
| H2B old mutation | 15 / 46 | 0 / 1 | 354 / 354 | yes, byte-identical | yes / yes |

The reconstructed OpenAI message arrays have identical canonical byte hashes
to their FULL arrays. This is stronger than equality of token counts.

## Oversized-observation activation controls

Two clearly labelled derived trajectories add 96 deterministic diagnostic
lines only to the designated historical observation. The system prompt, task,
all other turns, and historical reference decision are unchanged. The lines
carry no paths or failure/mutation facts and exist only to test the receipt
mechanism above its size gate.

| Case / arm | Valid action | Exact command vs FULL-B | Action phase | Full / materialized tokens | Materialized saving |
|---|---:|---:|---|---:|---:|
| H1 FULL-B | yes | reference | terminal completion | 1,449 / 1,449 | 0% |
| H1 DROP | yes | no | terminal completion | 1,449 / 337 | 76.7% |
| H1 observation receipt | yes | no | terminal completion | 1,449 / 410 | 71.7% |
| H2B FULL-B | yes | reference | terminal completion | 1,410 / 1,410 | 0% |
| H2B DROP | yes | no | terminal completion | 1,410 / 278 | 80.3% |
| H2B observation receipt | yes | no | terminal completion | 1,410 / 385 | 72.7% |

The H1 receipt replaced a 1,082-token old search observation with 43 tokens,
saving 1,039 request tokens while retaining the original assistant action. It
costs 73 tokens more than DROP because DROP removes both the 30-token action and
the observation. The H2B receipt replaced a 1,071-token old mutation
observation with 46 tokens, saving 1,025 request tokens; it costs 107 tokens
more than DROP because it preserves the 61-token action and adds the receipt.

All candidate outputs were valid terminal `echo` actions indicating that the
synthetic task was complete. Exact command equality is not evidence of a
receipt failure here: H2B FULL-A/FULL-B was exact, but both candidates changed
only the terminal wording; H1 FULL-A/FULL-B itself changed terminal wording at
temperature zero. H1 exact divergence is therefore not attributable, and the
one-decision H2B result is too small to establish behavioral equivalence.

The receipt requests retained valid alternating roles, every receipt witness
was available in the evaluated prefix, and no complete future message content
appeared in either receipt. See `request_and_provenance_audit.json`.

The `*_comparison.{json,md}` files were generated by
`experiments.paper8_5_agent_memory.reduce_frozen_replays`. FULL-A is retained to
report repeatability; the comparisons use FULL-B as their frozen reference.
