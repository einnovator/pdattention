# Paper 8.5 matched-tail import into Paper 4.5

This receipt freezes the first 3/3 OpenHands qualification of the matched
causal-tail policy and narrows what Paper 4.5 is allowed to claim from it.

The transferable object is the ordered subset of whole causal records. A PRA
engine must attach those records' already-resident, original-position K/V. It
must report zero selected-history re-encoding and, for a zero-copy claim, zero
selected-K/V copy. Paper 8.5's additional slicing of oversized ordinary-text
observations is not imported: once the original K/V exists, regenerating a
compact textual observation would be new encoding rather than reuse.

The 46.86% paired saving is an agent-workload result that includes 35 fewer
actions. It is not an engine-local K/V omission or latency number. The native
engine cohort must report realized logical/KV retention, K/V identity and
position preservation, copy/re-encoding bytes, task resolution, and calls
separately.
