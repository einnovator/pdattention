# Changelog

## Evidence attribution correction

Earlier qualification tables used a simplified baseline label for some
Selected Context versus Native Memory comparisons. The evidence model now
distinguishes ordinary No-PRA inference from PRA Selected Context, Native
Memory, Native Serving, and exact bundle/adaptor conditions. Numerical
measurements are preserved; attribution labels and derived deltas have been
corrected.

## Engine evidence freshness correction

Agent-history qualification exposed cache reconstruction, original-position,
physical-copy accounting, consumer-transient, and lifecycle defects that were
not covered by the earlier bundle benchmark. Ten canonical native-runtime
records and their headline rows are now quarantined from public cards and the
evidence matrix. Structural bundle metadata and selection/router-only evidence
remain valid. Engine-dependent values will return only after rerun under the
versioned `live-kv-original-position-lifecycle-v1` contract with exact source
and gate commits.
